# StreamXMap 🗺️🎥

StreamXMap is a real-time, map-based platform that aggregates live streams (YouTube & Twitch) and visualizes active creators on an interactive geographical map using PostGIS and WebSockets.

## Features
- **Live Geospatial Tracking:** View active live streams pinned to their exact broadcast locations.
- **One-Tap Go-Live:** Automatically detect your active YouTube broadcast and bind your location to the map.
- **In-App Updates:** Built-in OTA version verification that alerts users when a fresh APK release is available.

## Download Android App (APK)
Grab the latest production-ready Android build directly from the [Releases Page](https://github.com/PythonicPete/streamsXmap/releases/tag/v1.0.0).

## Tech Stack
- **Frontend / Mobile:** Flutter, Google Maps, WebSockets
- **Backend:** Node.js, Express, PostgreSQL, PostGIS, Passport.js (Google OAuth 2.0)
- **Hosting:** Render & GitHub Releases
